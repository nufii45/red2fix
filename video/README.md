# Red2Fix demo video

- `pnpm snippets` regenerates `src/data/snippets.json` from `agent/review.py` (fails if a marker is gone).
- `pnpm exec remotion studio` previews `Red2FixDemo`; missing recordings show a slate. See RECORDING.md.
- `pnpm exec remotion render Red2FixDemo out/red2fix-demo.mp4` renders it.
